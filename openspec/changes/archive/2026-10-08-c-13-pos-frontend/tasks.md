# Tasks

> **Cómo aplicar**: 6 tandas (B1–B6). Cada tanda la aplica un sub-agente sin contexto previo en ~15–25 min: leer `proposal.md`, `design.md` (D1–D17, "Decisiones de UX", "Decisiones tomadas por defecto") y el spec indicado en la tanda. Cada tanda deja la app ejecutable y termina con su verificación. Governance **MEDIO**: implementar con checkpoints y reportar decisiones no obvias. TDD: lógica (stores, carrito, pagos, vuelto, idempotencia, lector, permisos, adaptadores de backend) con test failing primero (RED verificado) → GREEN → refactor; layout puro de forma pragmática. Reglas duras: sin `any` (tsconfig estricto), shadcn antes que UI propia, sin secretos en código, **sin commits ni pushes**, sin ARCA ni Mercado Pago en la UI. Comandos: frontend `cd frontend && npm test && npm run build`; backend `cd backend && pytest -q`.
